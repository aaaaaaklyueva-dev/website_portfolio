# Портфолио — Клюева Анастасия

Сайт-портфолио продуктового дизайнера. Один файл `index.html`, без сборки и зависимостей: все картинки, логотипы и видео уже встроены внутрь.

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `website_portfolio`).
2. Нажми **Add file → Upload files** и перетащи все файлы из этой папки, включая `.nojekyll`.
3. Открой **Settings → Pages**, в поле **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту сайт будет доступен по адресу `https://aaaaaaklyueva-dev.github.io/website_portfolio/`.

## Что где лежит

- `index.html` — весь сайт: тексты на русском и английском, стили, логика тем, проекты.
- `media/` — исходники видео и обложки, которые встроены в сайт. Сайту они не нужны, это копии для будущих правок.
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть.

## Где править

В `index.html` ищи по словам:
- `const T = {` — все тексты (`ru` и `en`).
- `PHOTO1` — фото в карточке «Фото 1» (сейчас пусто, показывается серая карточка).
- `COVERS` — обложки проектов в списке.
- `LINKS` — ссылки на Telegram, LinkedIn, резюме и Telegram-группу.
- `EMAIL` — почта в окне «Связаться».
- `DEMO_URL` — ссылка на кликабельное демо «Записи звонков».
